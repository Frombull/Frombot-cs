# Frombot-cs

Versão em C# do meu bot de discord em python [Frombot](https://github.com/Frombull/frombot).

- Feito com a biblioteca [Discord.Net](https://github.com/discord-net/Discord.Net)

## 🔧 Como rodar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Frombull/Frombot-cs.git
   cd frombot
   ```

2. Crie um arquivo `.env` na raiz do projeto com seu token:
   ```
   BOT_TOKEN=seu_token_aqui
   ```

3. Compile e execute o projeto:
   ```bash
   dotnet run
   ```

## 💬 Comandos disponíveis

- `!ping` → Pong!

## 📁 Estrutura

- `Commands/`  → Comandos do bot
- `Config/`    → Configurações do bot
- `Services/`  → Inicialização e lógica do bot
- `Program.cs` → Main
